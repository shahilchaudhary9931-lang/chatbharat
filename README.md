# **Bhasha Chat**

Create a WhatsApp-like mobile chat application in Hindi and English.



Features:

- Mobile number login with OTP

- User profile with name and photo

- Contact list

- One-to-one real-time chat

- Group chat creation

- Send text messages

- Send photos, videos and voice notes

- Message status: sent, delivered, seen

- Online/offline status

- Search users and chats

- Notifications for new messages

- Status/Stories feature

- Dark mode

- Clean modern UI similar to WhatsApp



Pages:

1. Splash screen

2. Login screen

3. OTP verification screen

4. Home screen with Chats, Status, Calls tabs

5. Chat screen

6. Group creation screen

7. Profile/settings screen



Backend:

- Firebase Authentication

- Firebase Realtime Database or Firestore

- Push notifications

- Secure user data



Design:

Use green-and-white chat style, simple icons, fast loading, mobile friendly.
